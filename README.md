# Chemistry Calculator

A Python-based chemistry calculator designed to automate chemical calculations and stoichiometry.

## Features

- Molar mass calculation
- Mass-to-mole conversion
- Automatic chemical equation balancing
- Support for nested parentheses in chemical formulas
- Empirical formula calculation

## Dependencies

- Python 3.10 or newer
- Periodictable
- SymPy

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
